## 3. 공통 UI 규칙

| 구분 | 규칙 |
|---|---|
| 해상도 | 데스크톱 우선 (최소 1280px). 모바일은 MVP 범위에서 제외 |
| 레이아웃 | 상단 헤더 + 본문. 관리자 화면은 좌측 사이드바 추가 |
| 헤더 (구직자) | 로고(홈 이동), [새 면접], [면접 이력], 이름 드롭다운([내 정보], [로그아웃]) |
| 사이드바 (관리자) | 대시보드, 회원 관리, 질문 관리, 면접 관리. 하단 [로그아웃] |
| 권한 처리 | 비로그인 상태로 보호 화면 접근 → SCR-C01. 구직자가 `/admin` 접근 → SCR-U01. 토큰 만료 → "다시 로그인해주세요." 후 SCR-C01 |
| 로딩 | 1초 이상 걸리는 요청은 버튼을 비활성화하고 스피너 표시. LLM 대기는 안내 문구 표시 (SCR-U03 참고) |
| 오류 | 입력 오류는 입력창 아래 빨간 문구, 서버 오류는 화면 상단 토스트 ("잠시 후 다시 시도해주세요.") |
| 확인 창 | 되돌릴 수 없는 동작(면접 중단, 회원 탈퇴, 질문 삭제)은 확인 모달을 거친다 |
| 빈 상태 | 목록이 비면 안내 문구와 다음 행동 버튼을 보여준다 (예: "아직 본 면접이 없어요" + [첫 면접 시작하기]) |
| 디자인 참고 | 외부 서비스 디자인을 참고해 색상·폰트를 정한다. 폰트 기본값은 Pretendard |

## 4. 화면 상세

와이어프레임의 `[n]` 번호는 아래 구성 요소 표의 번호와 같다.

### SCR-C01 로그인

```
┌──────────────────────────────────────────────
│                 AI 모의면접
│
│     [1] 이메일      ┌──────────────────┐
│     [2] 비밀번호    ┌──────────────────┐
│     [3] ( 로그인 )
│     [4] 아직 회원이 아니신가요? 회원가입
└──────────────────────────────────────────────
```

| No | 요소 | 타입 | 설명·규칙 |
|---|---|---|---|
| 1 | 이메일 | 입력 | 이메일 형식 검사 |
| 2 | 비밀번호 | 입력(password) | Enter 키로 로그인 |
| 3 | 로그인 | 버튼 | 둘 다 입력해야 활성화. 성공 시 역할별 홈으로 이동 |
| 4 | 회원가입 | 링크 | SCR-C02로 이동 |

| 이벤트 | 결과 |
|---|---|
| 로그인 실패 | [2] 아래 "이메일 또는 비밀번호가 올바르지 않습니다." |
| 비활성 계정 | "이용이 제한된 계정입니다." |

### SCR-C02 회원가입

```
┌──────────────────────────────────────────────
│                 회원가입
│     [1] 이메일          ┌──────────────────┐
│     [2] 비밀번호        ┌──────────────────┐   8자 이상, 영문+숫자
│     [3] 비밀번호 확인   ┌──────────────────┐
│     [4] 이름            ┌──────────────────┐
│     [5] ( 가입하기 )
│     [6] 이미 계정이 있으신가요? 로그인
└──────────────────────────────────────────────
```

| No | 요소 | 타입 | 설명·규칙 |
|---|---|---|---|
| 1 | 이메일 | 입력 | 포커스가 빠질 때 형식 검사. 중복은 제출 시 서버 응답으로 표시 |
| 2 | 비밀번호 | 입력(password) | 8자 이상, 영문+숫자. 조건 미충족 시 안내 문구 |
| 3 | 비밀번호 확인 | 입력(password) | [2]와 다르면 "비밀번호가 일치하지 않습니다." |
| 4 | 이름 | 입력 | 1~20자 |
| 5 | 가입하기 | 버튼 | 모든 검사 통과 시 활성화. 성공 시 토스트 "가입이 완료되었습니다." 후 SCR-C01 |
| 6 | 로그인 | 링크 | SCR-C01로 이동 |

### SCR-C03 내 정보

```
┌──────────────────────────────────────────────
│ 헤더
├──────────────────────────────────────────────
│  내 정보
│   [1] 이메일   user@example.com (수정 불가)
│   [2] 이름     ┌──────────┐  [3] ( 저장 )
│
│  비밀번호 변경
│   [4] 현재 비밀번호 / 새 비밀번호 / 새 비밀번호 확인
│   [5] ( 비밀번호 변경 )
│
│  [6] 회원 탈퇴 (구직자만 표시)
└──────────────────────────────────────────────
```

| No | 요소 | 타입 | 설명·규칙 |
|---|---|---|---|
| 1 | 이메일 | 텍스트 | 읽기 전용 |
| 2~3 | 이름, 저장 | 입력, 버튼 | 값이 바뀌면 [3] 활성화 |
| 4~5 | 비밀번호 변경 | 입력, 버튼 | 규칙은 SCR-C02와 같음. 현재 비밀번호가 틀리면 오류 문구 |
| 6 | 회원 탈퇴 | 텍스트 버튼 | 확인 모달: "면접 기록과 녹음 파일이 모두 삭제되며 되돌릴 수 없습니다." + 비밀번호 입력 + [탈퇴하기]. 완료 후 SCR-C01 |

### SCR-U01 구직자 홈

```
┌──────────────────────────────────────────────
│ 헤더
├──────────────────────────────────────────────
│  [1] 안녕하세요, 성준님
│  [2] ( + 새 모의면접 시작하기 )
│
│  [3] 진행 중인 면접 (있을 때만)
│      백엔드 개발 · 보통 · 2/5 진행      ( 이어하기 )
│
│  [4] 최근 면접                         [5] 전체보기 >
│   ┌ 10/24 백엔드 개발 · 보통 · 78점 ┐ ┌ 10/22 … ┐ ┌ … ┐
│
│  [6] 내 점수 추이 (완료된 면접 2개 이상일 때)
│      개념 이해도 / 문제 해결력 / 커뮤니케이션 선 그래프
└──────────────────────────────────────────────
```

| No | 요소 | 타입 | 설명·규칙 |
|---|---|---|---|
| 1 | 인사말 | 텍스트 | 로그인 사용자 이름 |
| 2 | 새 면접 | 버튼 | SCR-U02로 이동 |
| 3 | 진행 중인 면접 | 카드 | `in_progress` 면접이 있을 때만 표시. [이어하기] → SCR-U03 |
| 4 | 최근 면접 | 카드 목록 | 최근 3개. 날짜, 직무, 난이도, 종합 점수(생성 중이면 "리포트 생성 중"). 클릭 → SCR-U04 |
| 5 | 전체보기 | 링크 | SCR-U05로 이동 |
| 6 | 점수 추이 | 선 그래프 | 최근 10개 완료 면접의 항목별 점수 (INT-10, 선택 기능) |

### SCR-U02 면접 설정

```
┌──────────────────────────────────────────────
│ 헤더
├──────────────────────────────────────────────
│  모의면접 설정
│   [1] 직무        ▼ 백엔드 개발
│   [2] 질문 유형   ( 기술 ) ( 인성 ) (● 혼합 )
│   [3] 난이도      ( 쉬움 ) (● 보통 ) ( 어려움 )
│   [4] 본질문 수   ◀ 5 ▶   (3~10개, 꼬리질문은 별도)
│
│   [5] 마이크·스피커 확인
│       마이크 ▂▃▅▃▂ (말해보세요)      ( ▶ 테스트 음성 듣기 )
│
│   [6] 안내
│     · AI 면접관이 질문을 음성으로 말하고, 답변은 말로 하면 돼요.
│     · 이어폰을 쓰면 소리가 울리지 않아요.
│     · 말을 마치고 2.5초쯤 조용하면 답변이 끝난 걸로 처리돼요. [답변 완료]를 눌러도 돼요.
│
│   [7] ( 면접 시작 )
└──────────────────────────────────────────────
```

| No | 요소 | 타입 | 설명·규칙 |
| --- | --- | --- | --- |
| 1 | 직무 | 드롭다운 | `GET /interviews/options`의 직무 목록 |
| 2 | 질문 유형 | 라디오 | 기본 '혼합' |
| 3 | 난이도 | 라디오 | 기본 '보통' |
| 4 | 본질문 수 | 숫자 스테퍼 | 3~10, 기본 5 |
| 5 | 마이크·스피커 확인 | 레벨 미터, 버튼 | 화면에 들어오면 마이크 권한 요청. 입력 크기를 막대로 표시. [테스트 음성 듣기]는 TTS로 만든 고정 문장 재생 |
| 6 | 안내 | 텍스트 | 고정 문구 |
| 7 | 면접 시작 | 버튼 | `POST /interviews` → SCR-U03 |

| 이벤트 | 결과 |
| --- | --- |
| 마이크 권한 거부 | [5]에 "마이크를 쓸 수 없어 텍스트로 진행해요." 표시. 시작은 가능 (텍스트 모드) |
| 질문 부족 | [7] 아래 "선택한 조건의 질문이 부족합니다. 조건을 바꿔주세요." |
| 진행 중 면접 있음 | 확인 모달: "진행 중인 면접이 있어요. 새로 시작하면 이전 면접은 중단됩니다." |

### SCR-U03 면접 진행

음성 모드가 기본이고, 마이크를 쓸 수 없거나 연결에 실패하면 텍스트 모드로 바뀐다.

```
┌──────────────────────────────────────────────
│ [1] 백엔드 개발 · 보통   본질문 2 / 5 ■■□□□   [2] ● 음성 연결됨   [3] ( 면접 중단 )
├──────────────────────────────────────────────
│  [4] AI 면접관 (말할 때 파형이 움직임)          [5] 상태: 듣는 중
│      자막: Q2. MSA를 도입한 경험이 있나요?
│
│  [6] 내 답변 (실시간 자막)
│      네, 주문 서비스를 분리하면서 …
│  [7] 마이크 ▂▃▅▃▂        답변 시간 01:12 / 03:00
│
│  [8] ( 답변 완료 )                 [9] 텍스트로 답변하기
├──────────────────────────────────────────────
│  [10] 지난 질문과 답변 ▸ (접힘)
└──────────────────────────────────────────────
```

| No | 요소 | 타입 | 설명·규칙 |
| --- | --- | --- | --- |
| 1 | 진행 정보 | 텍스트, 진행 바 | 직무, 난이도, 본질문 진행률. 꼬리질문은 진행률에 포함하지 않음 |
| 2 | 연결 상태 | 상태 표시 | 연결 중(회색) / 음성 연결됨(초록) / 재연결 중(노랑) / 텍스트 모드(회색) |
| 3 | 면접 중단 | 버튼 | 확인 모달 "중단하면 리포트가 만들어지지 않아요." → `POST /abort` → SCR-U01 |
| 4 | AI 면접관 | 아바타, 파형, 자막 | DataChannel `question`의 문장을 자막으로 표시. 꼬리질문이면 "꼬리질문" 라벨. TTS가 나오는 동안 파형 표시 |
| 5 | 상태 | 텍스트 | 아래 상태 표 참고 |
| 6 | 내 답변 자막 | 텍스트 | `partial` 메시지를 받을 때마다 갱신. 답변이 끝나면 `answer_saved`의 최종 문장으로 고정 |
| 7 | 마이크 레벨, 답변 시간 | 레벨 미터, 타이머 | 듣는 중에만 표시. 3분이 되면 자동 종료 |
| 8 | 답변 완료 | 버튼 | 듣는 중에만 활성화. DataChannel `answer_done` 전송 |
| 9 | 텍스트로 답변하기 | 링크 | 확인 후 `switch_text` 전송, 아래 텍스트 모드로 전환 |
| 10 | 지난 질문과 답변 | 접기·펼치기 | 이번 면접의 이전 질문과 최종 답변 목록 |

상태별 화면:

| 상태 | [5] 문구 | [4] | [6]~[8] |
| --- | --- | --- | --- |
| `ai_speaking` | 면접관이 말하는 중 | 파형 움직임, 자막 표시 | 숨김. 마이크 입력은 서버에서 무시 |
| `listening` | 듣는 중 | 자막 유지 | 자막·레벨·타이머 표시, [답변 완료] 활성 |
| `thinking` | 답변을 검토하고 있어요 | 맞장구 음성 중 파형, 이후 점 세 개 애니메이션 | 최종 답변 표시, [답변 완료] 비활성 |

텍스트 모드: [4]의 자막은 그대로 쓰고(음성 없음), [6]~[8] 자리에 여러 줄 입력창(1~2,000자)과 [답변 제출] 버튼을 둔다. 제출은 `POST /interviews/{id}/answers`.

| 이벤트 | 결과 |
| --- | --- |
| 음성 연결 실패 (10초) | 모달 "음성 연결에 실패했어요. 텍스트로 진행할까요?" [다시 연결] [텍스트로 진행] |

| 15초 동안 말이 없음 | [6]에 "편하게 답변을 시작해주세요" |

| 끼어들기 (INT-13, 선택) | 면접관이 말하는 중 지원자가 말하면 TTS를 멈추고 듣는 중으로 전환 |
| 마지막 답변 저장 | `finished` 수신 → "면접이 끝났어요. 리포트를 만들고 있어요." 후 SCR-U04로 이동 |
| 새로고침·재접속 | 다시 연결한 뒤 `GET /interviews/{id}`로 대화를 불러오고, 마지막 미답변 질문을 음성으로 다시 들려줌 |

### SCR-U04 피드백 리포트

생성 중 상태:
```
┌──────────────────────────────────────────────
│ 헤더
├──────────────────────────────────────────────
│        ⏳ 리포트를 만들고 있어요 (보통 1~3분)
│        문항별 평가 2 / 5 완료
│        [8] (실패 시) 리포트 생성에 실패했어요. ( 다시 만들기 )
└──────────────────────────────────────────────
```

완료 상태:
```
┌──────────────────────────────────────────────
│ 헤더                                (관리자: 응시자 성준 · ( 목록으로 ))
├──────────────────────────────────────────────
│  [1] 2026-10-24 · 백엔드 개발 · 보통 · 본질문 5개 · 소요 18분
│
│  [2] 종합 점수  78 / 100        [3] 항목별 점수 (레이더 차트)
│                                     개념 이해도 4.2 / 문제 해결력 3.6 / 커뮤니케이션 3.9
│  [4] 종합 평가
│      기술 개념은 정확하지만 경험을 구조화해 설명하는 연습이 필요합니다.
│  [5] 강점 ✓ … ✓ … ✓ …          개선점 △ … △ … △ …
│
│  [6] 문항별 피드백
│   ▼ Q1. 자기소개와 지원 동기를 말씀해주세요.       4 · 3 · 4
│      내 답변: 저는 …     [▶ 녹음 듣기]
│      ↳ 꼬리질문: …   내 답변: …
│      피드백: …
│      [7] 모범 답변 예시 보기 ▸
│   ▶ Q2. MSA를 도입한 경험이 있나요?               3 · 3 · 4
│   ▶ …
│
│  ( 새 면접 시작하기 )   ( 면접 이력 )
└──────────────────────────────────────────────
```

| No | 요소 | 타입 | 설명·규칙 |
|---|---|---|---|
| 1 | 면접 정보 | 텍스트 | 날짜, 직무, 난이도, 본질문 수, 소요 시간 |
| 2 | 종합 점수 | 숫자 강조 | 100점 환산 |
| 3 | 항목별 점수 | 레이더 차트 + 숫자 | 5점 척도 세 항목 |
| 4 | 종합 평가 | 텍스트 | LLM 요약 |
| 5 | 강점·개선점 | 목록 | 각 3개 |
| 6 | 문항별 피드백 | 아코디언 | 첫 문항만 펼침. 헤더에 세 항목 점수. 음성 답변이면 [녹음 듣기] |
| 7 | 모범 답변 | 접기·펼치기 | 기본 접힘 |
| 8 | 다시 만들기 | 버튼 | `failed`일 때만 표시. `POST /report/retry` 후 생성 중 상태로 전환 |

| 이벤트 | 결과 |
|---|---|
| 생성 중 | 3초마다 상태 조회. `done`이 되면 완료 화면으로 전환 |
| 중단된 면접 | "중단된 면접은 리포트가 없어요." + [면접 이력] |
| 다른 사람의 리포트 접근 | 403 → "접근 권한이 없습니다." 후 SCR-U01 |
