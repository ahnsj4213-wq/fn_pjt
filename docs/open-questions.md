# 미결정 사항과 PRD 해석 질문

PRD가 이미 확정한 항목(11.1 X-01~X-10, X-12)은 여기에 다시 올리지 않는다. 여기에는 (1) PRD가 미결정으로 남긴 항목, (2) PRD 문장 사이의 불일치나 빈칸, (3) 구현을 위해 임시로 정한 해석을 모은다.

- **결정 주체**: 팀(PRD 소유자) / 법률 / 기술(ADR로 결정 가능)
- **임시 처리**: 결정 전까지 구현이 따르는 안전한 기본값. 기술 결정은 ADR에 기록하고, 팀·법률 결정은 확정된 요구사항처럼 다루지 않는다.
