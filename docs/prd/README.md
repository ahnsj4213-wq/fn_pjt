# PRD 원본 안내

- 기준 문서(Source of Truth): `통합 PRD.pdf` (v1.0 초안, 2026-10-26, 25쪽). 원본은 사용자 로컬 `C:\Users\mega\Downloads\통합 PRD.pdf`에 있으며 이 저장소에 복사하지 않았다.
- `integrated-prd.extracted.txt`는 `pdftotext -layout`으로 기계 추출한 텍스트다. **표의 칸 정렬이 깨진 곳이 있다**(특히 5.3 이력서, 5.7 평가의 우선순위 칸, 6.2·6.4·7.1 표). 우선순위·상태 전이는 PDF 페이지 이미지로 대조해 `docs/requirements-traceability.md`에 옮겼다. 해석이 갈리면 추출 텍스트가 아니라 PDF를 본다.
- PRD 본문이 언급하는 두 번째 탭 `[PRD 비교·통합 결정]`은 PDF에 포함되어 있지 않다 (`docs/open-questions.md` OQ-01).
