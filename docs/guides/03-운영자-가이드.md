# 운영자(관리자) 가이드

플랫폼 전체를 관리하는 **운영자**를 위한 안내서입니다. 운영자 화면은 메뉴가 두 개뿐입니다: **기업 인증**, **공고 관리**.

> 작성 기준: 2026-11-09 코드(`frontend/src/screens/operator/`)를 읽고 작성했습니다. 실제 화면을 띄워 확인한 것은 아닙니다.
> 확인하지 못한 것: 운영자 계정을 어떻게 만드는지, 서버 설치·배포 절차는 이 가이드에서 다루지 않습니다(배포는 `deploy/README.md`, 보관 삭제는 `docs/data-retention.md` 참고).

## 1. 접근 방식
- 로그인한 뒤 `/operator` 주소로 들어갑니다. 화면은 운영자 역할만 열 수 있고, **서버가 다시 한 번 권한을 확인합니다**(주소를 알아도 다른 역할은 못 씁니다).
- 지원자와 기업회원은 이 화면의 데이터에 접근할 수 없습니다.

## 2. 기업 인증 (`/operator`)
기업회원 가입 신청을 확인하고 승인하는 화면입니다. 왼쪽 메뉴의 "기업 인증" 옆 숫자는 **검토 필요** 건수입니다.

| 상태 | 뜻 |
|---|---|
| 자동 승인 | 회사 메일(회사 도메인)로 인증한 기업. 운영자가 할 일이 없습니다. |
| 검토 필요 | 개인 메일로 가입했고 증빙을 확인해야 하는 기업 |
| 승인 | 운영자가 승인함 |
| 반려 | 운영자가 반려함 (사유가 기업에 전달됨) |

화면 위에 상태별 건수가 표시되고, 표에는 회사, 담당자, 이메일, 사업자등록번호, **확인 방법**(회사 메일 인증 / 운영자 발급 / 개인 메일), 증빙, 신청일, 상태가 나옵니다.

### 처리 방법
1. 안내 문구대로 **개인 메일로 가입한 기업만** 증빙을 보고 판단하세요.
2. **승인**: 누르면 바로 승인되고, 그 기업은 공고를 게시할 수 있습니다.
3. **반려**: **반려 사유를 반드시 입력**하고 "반려 확정"을 누릅니다. 사유는 기업 화면에 표시되며, 기업은 서류를 다시 올려 재신청할 수 있습니다.

## 3. 공고 관리 (`/operator/postings`)
문제가 있는 공고를 숨기고, 필요하면 기업회원을 정지합니다.

| 버튼 | 동작 |
|---|---|
| 숨기기 / 다시 보이기 | 공고를 메인 화면에서 **바로 내립니다**(삭제 아님). 기업 화면에는 "숨김 — 운영자가 숨김 처리"로 표시됩니다. 다시 보이기로 되돌릴 수 있습니다. |
| 기업 정지 / 정지 해제 | 그 기업의 **공고가 모두 내려가고 새 공고를 게시할 수 없게** 됩니다. 해제하면 풀립니다. |

표 열: 공고, 회사(정지 중이면 "정지" 표시), 직무, 상태(게시 중/마감/숨김).

## 4. 기업과의 소통
- 기업 담당자의 **문의 쪽지** 화면에는 "응시자"와 "운영자" 두 종류가 나옵니다. 운영팀이 기업에 보낸 쪽지는 기업 화면에서 운영자 이름으로 표시됩니다.
- 기업이 정지·반려 상태일 때 화면에 "운영팀에 문의해 달라"는 안내가 나옵니다.

## 5. 운영자가 알아 둘 것 (정책)
- **AI는 합격·불합격을 정하지 않습니다.** 합격 여부는 기업 담당자가 정합니다. 운영자는 개별 지원자의 결정에 개입하지 않습니다.
- 지원자 개인정보 접근은 목적에 맞는 범위로 제한되며, 감사 로그가 남습니다.
- 데이터 보관 기간이 지나면 자동 삭제됩니다(음성 → 내용 순서의 2단계). 운영자 CLI 명령 `python -m app.cli purge [--dry-run]`로 삭제 대상을 미리 볼 수 있습니다. (이 명령은 2026-10-28 인수인계 문서 기준이며 이번에 다시 실행해 확인하지는 않았습니다.)
- 모든 AI 처리는 사내 서버 안에서 이뤄지며 외부 AI API를 쓰지 않습니다.
