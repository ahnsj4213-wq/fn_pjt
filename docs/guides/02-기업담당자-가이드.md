# 기업 담당자(채용담당자) 가이드

공고를 올리고, 지원자의 AI 면접 결과를 검토해 합격 여부를 정하는 **기업회원**을 위한 안내서입니다.

> 작성 기준: 2026-11-09 코드(`frontend/src/screens/recruiter/`, `backend/app/recruiter/`)를 읽고 작성했습니다. 실제 화면을 띄워 확인한 것은 아닙니다.
> 참고: 코드에는 기업별 계정과 운영자 인증(승인) 절차가 구현되어 있습니다. `CLAUDE.md` §0의 "단일 관리자" 결정과 다른 부분이라, 이 가이드는 **코드에 있는 그대로** 적었습니다.

## 1. 한눈에 보기

```
기업회원 가입 → (운영자 승인) → 공고 등록·게시 → 면접 질문·평가 항목 설정 → 지원자 응시
   → 응시자 목록에서 결과 검토 → 합격/보류/불합격 결정 → 메일 안내
```

- AI는 점수와 근거를 만들 뿐, **합격·불합격은 담당자가 직접 정합니다.**
- 지원자가 "결과를 기업에 공유"에 동의하고 **우리 공고로 면접을 본 경우에만** 응시자 목록에 보입니다. 연습 모드로 본 면접은 보이지 않습니다.

## 2. 가입과 기업 인증

로그인 화면의 **채용담당자** 탭에서 로그인하고, "기업회원 가입"으로 가입합니다.

| 가입 방식 | 인증 결과 |
|---|---|
| 회사 메일(회사 도메인 메일) | **자동 승인** |
| 개인 메일 | 운영자가 **재직증명서·사업자등록증 등 증빙**을 보고 승인 (PDF·JPG·PNG) |

- 승인 전에는 화면 위쪽에 안내가 뜹니다. **승인 전에는 공고를 게시할 수 없고(임시 저장만 가능)**, 나머지 메뉴는 미리 둘러볼 수 있습니다.
- 개인 메일로 가입했다면 안내줄의 링크로 증빙 서류를 올립니다. 운영자가 확인합니다.
- **반려**되면 사유가 화면에 표시되고, 서류를 다시 올릴 수 있습니다.
- 운영자가 기업을 **정지**하면 공고가 모두 내려가고 새 공고를 올릴 수 없습니다. 운영팀에 문의하세요.

## 3. 메뉴

왼쪽 메뉴(기업 관리): 대시보드 / 응시자 목록 / 일정 관리 / 면접 질문 관리 / 공고 관리 / 문의 쪽지

## 4. 대시보드
- 카드: 이번 달 응시자(지난달 대비), 게시 중인 공고와 조회수 합계, **결과 검토 대기**(면접은 끝났고 아직 결정하지 않은 응시자), 면접 완료율
- 공고별 합격률(합격 ÷ 담당자가 결정한 응시자). 직무마다 기준이 달라서 공고를 섞은 전체 합격률은 보여 주지 않습니다.
- 직무별 평균 점수, 공고별 성과(조회수·응시자·응시 전환율), 다가오는 일정, 최근 6개월 월별 응시자 수

## 5. 공고 관리

### 5.1 공고 등록
**새 공고 등록**에서 아래를 입력합니다.

| 항목 | 설명 |
|---|---|
| 공고 제목 (필수) | 예: 백엔드 개발자 (신입) |
| 직무 카테고리 | 개발 / 데이터·AI / 디자인 / 마케팅 / 경영지원 |
| 경력·고용형태·근무지·모집 인원(1~99)·마감일 | 마감일이 지나면 **자동 마감**됩니다. |
| 주요 업무 / 자격 요건 / 우대 사항 | 이 내용은 **면접 질문을 만들 때도 쓰입니다.** |
| 코딩테스트 | 켜면 제한 시간(10~180분)과 난이도(쉽게/보통/어렵게)를 고릅니다. 문제는 지원자마다 서버가 정합니다. |

버튼:
- **임시 저장**: 작성 중 상태로 저장
- **게시하기**: 지원자 메인 화면에 바로 노출 (기업 인증 승인 후)
- **미리보기**, **템플릿 불러오기**, **템플릿으로 저장**(마감일은 저장하지 않음)
- **회사 자료로 초안 작성**: 제목을 먼저 입력하면 올려 둔 회사 자료로 빈 칸을 채웁니다. 게시 전에 내용을 꼭 확인하세요.

### 5.2 공고 목록
- 상태: 게시 중 / 작성 중 / 마감 (운영자가 숨기면 **숨김**으로 표시)
- 관리: 수정(작성 중이면 "이어서 작성"), 미리보기, **마감**(메인 화면에서 내려감), **삭제**(지원자 화면에서 바로 사라지며 되돌릴 수 없음)

## 6. 면접 질문 관리 (평가 설정)
공고마다 설정합니다. **첫 면접이 시작된 공고는 질문 설정을 바꿀 수 없습니다.** 저장하면 **다음 면접부터** 적용됩니다.

1. **질문 분야**: 인성 / 지원 동기 / 직무 기술 / 프로젝트 경험 / 협업 중 하나 이상
2. **질문 목록**: 칸마다 분야를 고르고, 질문을 직접 쓰거나 **비워 두면 AI가 만듭니다.** (질문 칸 추가·빼기, 최대 10개)
3. **평가 항목 가중치**: 전문성·논리성·표현 및 태도·전달력(+ 코딩테스트를 켠 경우) 각각 0~60%, 5% 단위. **합계가 100%가 아니면 저장되지 않습니다.** "비율 유지하며 100%로 맞추기" 버튼이 있습니다.
4. **평가 항목 추가**: 직무별 추천 항목(예: 기술 이해도, 문제 해결력)을 고르거나 직접 이름·설명·상/중/하 기준을 써서 **최대 5개**까지 추가할 수 있습니다. 새 항목 가중치는 10%로 시작합니다.
5. **면접 설정**: 생각할 시간(5/10/20/30초), 답변 제한시간(30/60/90/120초), 꼬리질문 최대 횟수(묻지 않기~4회). 예상 소요 시간이 표시됩니다.
   - 꼬리질문은 답변이 모호하거나, 이력서와 맞지 않거나, 앞뒤 논리가 어긋날 때, 음성 인식 결과가 비었을 때 물어봅니다.
6. **초기화**: 질문 분야·질문 목록·면접 설정을 처음 상태로 되돌립니다(가중치는 그대로).

## 7. 응시자 목록과 결정

### 7.1 응시자 목록
- 필터: 공고, 담당자 결정(검토 전/합격/보류/불합격)
- 열: 이름, 공고, 응시일, 면접 진행, **AI 종합 점수**, **AI 예상 합격**, 담당자 결정, 리포트 버튼
- 평가가 끝나지 않으면 리포트가 없습니다.
- **AI 예상 합격**은 총점으로 **프로그램이 계산한 참고값**입니다(75점 이상 합격 추천, 65~74점 보류, 그 미만 불합격 추천). 모델이 정하는 값이 아니고, 지원자에게는 보이지 않습니다. 최종 결정은 아래 담당자 결정 칸에 담당자가 정한 값만 뜻합니다.

### 7.2 응시자 상세
- 상단: **합격 / 보류 / 불합격** 버튼(담당자 결정), 평가 리포트, **메일 보내기**, **다시 평가**(가능할 때만)
- 평가가 끝나야 결정할 수 있습니다. 평가가 보류(ON_HOLD)면 **다시 평가**를 눌러 주세요. 지원자는 다시 면접을 볼 필요가 없습니다.
- 면접을 끝까지 마치지 않았다면(중도 종료) 종합 점수가 없다는 안내가 뜹니다(답한 질문 수 표시).
- **보류**는 담당자만 보는 상태입니다. 지원자에게는 계속 "검토 중"으로 보이고, **합격·불합격으로 정하면 결과가 공개**됩니다.
- 본문: 이력서(지원 시점 사본, 원본 파일 보기), 연락처·이메일, 평가 리포트, **메모**(우리 회사 담당자에게만 보임), **결정 이력**(누가·언제·무엇에서 무엇으로 바꿨는지)
- 결정은 버전 검사를 하므로, 다른 담당자가 먼저 바꿨다면 오류 메시지가 뜨고 화면이 새로 고쳐집니다.

### 7.3 평가 리포트 읽는 법
- **AI 종합 점수**: 항목별 점수 × 가중치를 서버가 계산한 값입니다.
- 항목별 점수 옆에 가중치가 보입니다. 근거가 부족해 점수를 내지 못한 항목 수도 표시됩니다.
- 질문별 답변과 점수 근거 인용문: 프로그램이 답변 원문과 대조해 검증한 문장입니다. **"근거 미연결 / 내용 부족 / 근거 추출 실패 / 답변 없음"**은 점수의 신뢰도를 알려 주는 표시입니다.
- 시선 이탈 횟수, 사용한 AI 모델·루브릭 버전도 표시됩니다.
- 코딩테스트: 출제 문제(Lv·제목), 자동 채점 통과 수, 정확성(테스트 실행 결과)·효율성·문제 해결 방식·코드 품질.

## 8. 메일 보내기
응시자 상세의 **메일 보내기**: 유형을 고르면 문안이 채워집니다(고쳐 쓸 수 있음).
- **2차 면접 일정 안내**: 면접 날짜를 고르면 지원자에게 수락/조율 요청 링크가 가고, 일정 관리에 "수락 대기"로 들어갑니다.
- **결과 안내**: 현재 결정(합격/불합격/검토 중)에 맞는 문안
- **직접 작성**
- 제목 앞에 `[회사명]`이 서버에서 붙습니다.

## 9. 일정 관리
달력에서 공고 마감, 면접, 결과 발표, 내부 일정을 관리합니다. 공고 마감일과 메일로 잡은 2차 면접은 **자동으로** 들어옵니다. 지원자가 수락한 면접 시간을 바꾸면 변경 메일이 갑니다. 공고 마감일은 공고 관리에서 공고를 수정해야 바뀝니다.

## 10. 문의 쪽지
지원자(결과 공유한 지원 건에서 "기업에 문의")와 운영팀이 보낸 쪽지를 보고 답장합니다. 읽지 않은 수가 메뉴에 표시됩니다.

## 11. 알아 둘 점
- 지원자의 이력서·답변 등 개인정보는 **개인정보 동의를 하고 결과 공유를 선택한 지원자**의 것만 보입니다.
- 지원자가 탈퇴하면 담당자 화면에는 "탈퇴한 지원자"로 나오고 내용은 삭제됩니다.
- 응시 기록 보관 기간이 지나면 자동 삭제됩니다.
- 평가가 실패해도 지원자의 응시 기록은 지워지지 않고, 재응시를 요구하지 않습니다. **다시 평가**로 복구합니다.
