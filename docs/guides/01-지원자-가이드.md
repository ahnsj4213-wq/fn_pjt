# 지원자 가이드

AI 모의면접 서비스를 쓰는 **지원자**를 위한 안내서입니다.

> 작성 기준: 2026-11-09 코드(`frontend/src/screens/candidate/`, 백엔드 API)를 읽고 작성했습니다. 실제 화면을 띄워 캡처하며 확인한 것은 아닙니다. 화면 문구는 코드에 적힌 그대로입니다.

## 1. 한눈에 보기

```
공고 고르기 → 로그인 → 환경 점검 → 개인정보 동의 + 이력서 → AI 면접 → (코딩테스트) → 면접 완료 → 리포트 확인
```

- 모든 AI 분석은 회사 서버 안에서 이뤄집니다. 이력서·답변·음성을 외부 AI 서비스로 보내지 않습니다.
- AI는 점수와 피드백을 만듭니다. **합격·불합격은 기업 담당자가 정합니다.**

## 2. 시작하기

### 2.1 공고 보기 (로그인 없이 가능)
- 메인 화면 `/`에서 직무 카테고리(전체·개발·데이터·AI·디자인·마케팅·경영지원)를 고르거나, 공고명·회사명으로 검색합니다.
- 오른쪽에 **마감 임박 TOP** 목록이 있습니다.
- 이미 지원한 공고는 목록에서 빠지고 **지원 현황**에 나옵니다.
- 처음이라면 "처음이십니까? 이용 방법 보기"를 누르세요. 공고 고르기 → 이력서 작성 → AI 모의면접 → 리포트 확인, 4장짜리 안내가 나옵니다.

### 2.2 회원가입·로그인
- 로그인 화면의 **지원자** 탭에서 아이디(이메일)와 비밀번호로 로그인합니다. 처음이면 "회원가입"을 누릅니다.
- 지원하려고 눌렀다가 로그인 화면으로 왔다면, 로그인 후 보던 공고로 돌아옵니다.
- 아이디·비밀번호를 잊었으면 "아이디·비밀번호 찾기"를 누릅니다.
- 보안상 로그인에 여러 번 실패하면 잠시 잠깁니다. 로그인 오류 메시지는 "아이디가 없다"와 "비밀번호가 틀렸다"를 구분해서 알려 주지 않습니다.
- 기업회원·운영자 계정으로는 지원할 수 없습니다.

## 3. 지원 순서

공고 상세에서 **AI 면접 지원하기**를 누르면 단계가 시작됩니다. 한 공고에는 **한 번만** 지원할 수 있습니다.

### 3.1 단계 1: 면접 환경 점검
카메라·마이크·스피커 세 가지가 모두 **정상**이어야 다음으로 갈 수 있습니다.

| 장치 | 하는 일 |
|---|---|
| 카메라 | 내 얼굴이 점선 안에 들어오는지 확인합니다. 영상은 **저장되지도, 서버로 보내지지도 않습니다** (화면 점검용). |
| 마이크 | **마이크 테스트**를 누르고 "안녕하십니까, 면접을 시작합니다"라고 말합니다. 목소리가 들리면 정상입니다. |
| 스피커 | **테스트 소리 재생**을 누르고 소리가 들리면 "들립니다"를 누릅니다. |

- 장치가 여러 개면 목록에서 바꿀 수 있습니다. 이어폰을 꽂으면 자동으로 다시 찾습니다.
- 막혔을 때 (화면이 알려 주는 대로):
  - "차단되어 있습니다" → 주소창 왼쪽 자물쇠에서 카메라·마이크를 **허용**하고 다시 시도
  - "다른 프로그램이 쓰고 있습니다" → 화상회의·녹음 앱을 끄고 다시 시도
  - "보안 연결로 접속해야…" → 주소가 `https` 또는 `localhost`인지 확인

### 3.2 단계 2: 개인정보 동의와 이력서
1. **개인정보 수집·이용 동의 (필수)**: 수집 항목·이용 목적·보관 기간 표를 읽고 "동의합니다"를 고릅니다. 동의하지 않으면 면접을 진행할 수 없습니다.
2. **결과 공유 (선택)**: 체크하면 면접 결과(음성·답변·점수)가 해당 기업에 공유되어 담당자가 합격 여부를 정합니다. **체크하지 않으면 "연습 모드"**로 진행되고 기업에는 아무것도 보이지 않습니다.
3. **이력서 (필수)**
   - 이미 등록한 이력서가 있으면 "이 이력서로 지원"으로 나옵니다.
   - 새로 올리려면 PDF·PNG·JPG를 끌어다 놓거나 눌러서 고릅니다. 여러 개 가능, 파일당 10MB까지.
   - AI가 파일을 읽어 이름·학력·경력·보유 기술·프로젝트를 채웁니다. **스캔 PDF·사진은 글자 인식(OCR)으로 읽습니다.** 흐리게 읽힌 칸은 표시되니 원본과 맞는지 확인하고 고치세요.
   - 파일을 못 읽거나 AI 서버가 응답하지 않으면 "이력서 직접 만들기"로 직접 쓸 수 있습니다.
   - 지원 시점의 이력서는 **사본으로 저장**됩니다. 나중에 이력서를 고쳐도 이미 낸 지원서는 바뀌지 않습니다.
4. 준비가 끝나면 버튼이 **면접 시작**으로 바뀝니다. 이때 AI가 공고와 이력서를 보고 질문을 만들어 두기 때문에 잠시 기다릴 수 있습니다.

## 4. AI 면접

### 4.1 시작하기 전에 꼭 알아 둘 것 ⚠️
- **면접 도중 창을 닫거나, 새로고침하거나, 다른 페이지로 가거나, 인터넷이 끊기면 면접은 그 자리에서 끝납니다. 이어서 하거나 다시 볼 수 없습니다.** (이 규칙은 서버가 지킵니다.)
- 이미 답한 질문까지는 평가됩니다. 진행 중이던 질문은 버려집니다.
- 같은 면접을 다른 창에서 또 열면 "다른 창에서 면접이 열려" 이 화면의 연결이 닫힙니다.
- 다른 창으로 이동하면 기록이 남고, 시선이 화면을 벗어나면 경고가 뜹니다. 경고가 3회 이상이면 "부정행위 의심 기록"이 남습니다. 이 기록은 경고·기록일 뿐 자동으로 불이익을 주지는 않습니다.

### 4.2 면접 진행
**면접 시작**을 누르면(브라우저 정책상 한 번은 눌러야 소리가 납니다) 면접관이 첫 질문을 읽습니다.

```
면접관이 질문을 읽음 → 생각할 시간(카운트다운) → 답변 → [답변 완료] → (필요하면 꼬리질문) → 다음 질문
```

| 항목 | 값 | 비고 |
|---|---|---|
| 본질문 수 | 공고 설정에 따름 (기본 10개) | 인성·지원 동기·직무 기술·프로젝트 경험·협업 분야 |
| 본질문 생각 시간 | 5·10·20·30초 중 공고가 정함 (기본 10초) | |
| 본질문 답변 시간 | 30·60·90·120초 중 공고가 정함 (기본 60초) | |
| 꼬리질문 | 질문당 최대 1개, 생각 5초 + 답변 45초 | 전체 상한은 공고 설정(0~4개, 기본 2개) |
| 라이브 코딩 질문 | 답변 180초 | 직무에 따라 첫 직무 질문이 코드 작성형일 수 있음 |

- **질문이 다 읽히기 전에는 마이크가 닫혀 있습니다.** 끝까지 들어 주세요.
- 말한 내용은 **실시간 자막**으로 보입니다.
- **[답변 완료]**를 누르면 답변이 확정됩니다. 시간이 끝나도 자동 확정됩니다. 조용히 있어도 저절로 끝나지는 않습니다.
- **질문 다시 듣기**는 질문당 1번, **바로 답변 시작**으로 생각 시간을 건너뛸 수 있습니다.
- 답변이 제한 시간의 2/3를 넘기면 면접관이 한 번 끼어들어 "핵심만 30초 안에 정리해 주십시오"라고 말합니다. 남은 시간 동안 이어서 답하면 됩니다.
- 남은 시간이 10초가 되면 경고가 보입니다.
- 마지막 질문에서는 버튼이 **답변 완료하고 면접 끝내기**로 바뀝니다.

### 4.3 문제가 생겼을 때
| 증상 | 원인·해결 |
|---|---|
| "질문 음성이 재생되지 않았습니다" | **소리 켜기** 버튼을 누르세요. |
| "마이크 소리가 서버에 전달되지 않고 있습니다" | 마이크 연결과 음소거를 확인하세요. |
| "음성 연결이 되지 않아 글로 답변하는 방식으로 진행합니다" | 면접 **시작 전** 음성 연결이 3번 실패한 경우에만 텍스트 모드로 바뀝니다. 답변란(최대 2,000자)에 글로 쓰고 **답변 완료**를 누릅니다. |
| "연결이 끊겨 면접이 종료되었습니다" | 면접 도중 연결이 끊기면 종료됩니다. 답변한 질문까지 평가됩니다. |
| "카메라 연결이 끊겼습니다" | 카메라 연결을 확인하세요. 다시 연결을 시도합니다. |

## 5. 코딩테스트 (공고가 켠 경우만)
- 면접이 끝나면 이어서 진행됩니다. 언어는 **Python**만 지원합니다.
- 문제는 지원자마다 서버가 정해 줍니다(Lv.0~5 중 직무·경력·난이도에 맞게).
- **[실행]**: 공개 예제로만 돌려서 **내 출력**과 **기대 출력**을 나란히 보여 줍니다. 정답 여부는 알려 주지 않습니다.
- **[최종 제출]**: 제출하면 더 이상 고칠 수 없습니다. 공개·비공개 테스트로 자동 채점되고 AI 면접 평가에 함께 반영됩니다. 비공개 테스트는 보여 주지 않습니다.
- 코드는 자동 저장됩니다("자동 저장됨" 표시). **제한 시간이 끝나면 마지막 저장본이 자동 제출**됩니다.
- 코드 실행 환경이 점검 중이면 "작성과 제출은 할 수 있습니다"라는 안내가 뜹니다.
- 실행 환경은 인터넷이 막혀 있고 시간·메모리 제한이 있습니다.

## 6. 면접이 끝난 뒤

### 6.1 면접 완료 화면
- 답변한 질문 수, 꼬리질문 수, 면접관 끼어들기 횟수, 시선 이탈 경고 횟수, 결과 공유 여부(또는 연습 모드), 소요 시간이 보입니다.
- 리포트가 만들어지는 진행 막대가 보입니다. 보통 20초 안팎이며, 이 화면을 열어 두면 완성되자마자 바뀝니다. 기다리지 않고 **리포트 보기**를 눌러도 됩니다.
- "평가가 지연되고 있습니다"가 뜨면 담당자가 확인 후 다시 평가합니다. **면접을 다시 볼 필요는 없습니다.**

### 6.2 결과 리포트
**마이페이지 → 지원 현황 → 리포트 보기**에서 봅니다.

- 총점, 등급(매우 우수 90↑ / 우수 80↑ / 양호 70↑ / 보통 60↑ / 노력 필요), AI 총평
- 영역별 평가 4가지: **전문성·논리성·표현 및 태도·전달력** (기업이 추가한 평가 항목, 코딩테스트 점수가 함께 나올 수 있음)
- 강점·개선점 1~3순위, 질문별 답변 원문(가점 구절·감점 구절 표시)과 점수 근거
- 답변 습관(부정적 표현 횟수, 질문별 답변 시간), 말의 속도·발음·음성 높낮이 같은 서버가 잰 값
- 세부 항목이 **"측정 없음"**으로 나오면, 그 항목의 세부 점수가 저장되지 않았다는 뜻입니다(예: 답변이 너무 짧거나 없음).
- 리포트의 AI 분석은 **연습을 돕기 위한 참고 자료**입니다.

### 6.3 내 영상·음성 삭제
- 면접 음성 원본은 분석이 끝나고 **정해진 기간(리포트 화면에 표시) 뒤 자동 영구 삭제**됩니다. **카메라 영상은 처음부터 저장하지 않습니다.**
- 리포트 화면의 **영상·음성 지금 삭제**로 바로 지울 수도 있습니다(되돌릴 수 없음). 점수와 텍스트는 남습니다.

### 6.4 채용 결과
- 기업이 합격·불합격을 정하면 지원 현황에 **채용 결과 보기**가 생기고, 공개된 피드백(잘한 점·보완할 점)을 볼 수 있습니다. 담당자가 결과 안내 메일을 보내면 메일로도 받습니다.
- 결정 전에는 "담당자가 검토 중입니다"라고 나옵니다.
- 연습 모드로 본 면접은 기업에 보이지 않으므로 결과 안내가 오지 않습니다.

## 7. 마이페이지

| 메뉴 | 할 수 있는 일 |
|---|---|
| 지원 현황 | 지원한 공고, 진행 상태, 리포트·결과 보기, **기업에 문의**(결과 공유한 지원 건) |
| 이력서 | 이력서 작성·수정·파일 업로드(PDF·DOCX·PNG·JPG, 10MB). 모든 공고에 쓰이는 이력서입니다. |
| 프로필 | 이름·생년월일·성별·연락처 수정, 비밀번호 변경 링크 메일 받기. 아이디(이메일)는 바꿀 수 없습니다. |
| 면접 일정 | 기업이 메일로 보낸 면접 일정. 메일에서 수락하거나 조율을 요청하면 여기에 반영됩니다. |
| 계정 | **회원 탈퇴** |

지원 현황의 "면접" 칸 표시: 완료 / 중도 종료 (질문 n/m) / 진행 중 / 응시 전. 중도 종료라도 답한 질문이 있으면 리포트를 볼 수 있습니다. **[다시 지원]이나 [이어서 하기]는 없습니다.**

## 8. 회원 탈퇴
- 비밀번호를 한 번 더 입력해야 합니다.
- 계정 정보, 등록 이력서·파일, 지원 건의 이력서 사본, 면접 답변·음성, 코딩 제출, 평가 결과가 **바로 삭제되고 되돌릴 수 없습니다.**
- 개인정보 동의 기록과 채용 결정 기록은 개인정보 없이 남습니다.
- 면접이나 코딩테스트를 진행 중이면 끝낸 뒤에 탈퇴할 수 있습니다.

## 9. 자주 묻는 질문

**Q. 면접을 중간에 쉬었다가 이어서 할 수 있나요?** 아니요. 도중에 나가면 그대로 종료되고 다시 볼 수 없습니다.
**Q. 같은 공고에 두 번 지원할 수 있나요?** 아니요. 공고당 1회입니다.
**Q. 카메라 영상이 저장되나요?** 아니요. 본인 화면을 보여 주는 용도이며 저장·전송하지 않습니다.
**Q. AI가 합격을 정하나요?** 아니요. 점수와 피드백만 만들고, 합격 여부는 기업 담당자가 정합니다.
**Q. 점수는 누가 계산하나요?** AI가 항목별 1~5점 판단을 내면 서버 프로그램이 정해진 공식으로 총점을 계산합니다.
**Q. 내 답변이 이상하게 인용된 것 같아요.** 리포트의 점수 근거 문장은 프로그램이 내 답변 원문의 번호 붙은 문장과 대조한 것입니다. 근거를 찾지 못한 항목은 그렇다고 표시됩니다("근거 미연결", "내용 부족" 등).
