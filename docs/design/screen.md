# AI 모의면접 플랫폼 화면정의서

지금 와이어프레임에 있는 화면을 그대로 정리한 문서입니다. 화면마다 누가, 어떻게 들어오고, 무엇이 있고, 누르면 어떻게 되는지를 적었습니다.

| 항목 | 내용 |
|---|---|
| 문서 | 화면정의서 v0.1 |
| 기준 | 모의면접 플랫폼 와이어프레임 버전 14 (https://claude.ai/artifact/XyZn4dD7mMHguA3q1eVrWK) |
| 작성일 | 2026-10-30 |
| 화면 수 | 33개 (공통 2, 지원자 15, 채용담당자 14, 운영자 2) · 캡처 38장 |

## 이 문서 읽는 법

- 화면 하나마다 화면 정보, 캡처, 구성 요소 표, 동작 규칙, 화면에 나오는 문구를 차례로 적었습니다.
- 캡처의 빨간 번호와 빨간 테두리는 바로 아래 구성 요소 표의 번호와 같습니다.
- 큰따옴표(" ") 안의 문장은 화면에 그대로 나오는 문구입니다. ○○ 자리에는 실제 이름, 날짜, 숫자가 들어갑니다.
- '작은 창'은 화면 위에 겹쳐 뜨는 창(모달)입니다. '알림 메시지'는 화면 아래쪽에 잠깐 떴다가 사라지는 한 줄 안내입니다.
- 사용자 이름은 와이어프레임에 쓰인 그대로 지원자, 채용담당자(기업회원), 운영자로 적었습니다.
- 화면 ID는 앞서 드린 기능정의서와 같은 번호를 쓰고, 기능정의서에 없는 화면에는 뒤 번호를 새로 붙였습니다. SC-R02는 와이어프레임에 없는 화면이라 비워 두었습니다.
- 캡처에 나오는 회사, 사람, 점수는 모두 화면 설계용 예시입니다. 캡처에서는 화면 아래의 시연용 막대를 숨겼습니다(7장).

## 2. 모든 화면에 같이 쓰는 규칙

- **입력 오류 표시:** 칸 바로 아래에 빨간 글씨로 오류 문장을 보여 주고, 틀린 칸 중 첫 번째 칸으로 커서를 옮깁니다. 고쳐서 다시 누르면 문장이 사라집니다.
- **알림 메시지:** 저장, 삭제, 발송처럼 일이 끝났을 때 화면 아래 가운데에 한 줄 안내가 떴다가 약 2.4초 뒤 사라집니다.
- **작은 창 닫기:** 오른쪽 위 × 버튼, 창 바깥 누르기, Esc 키 중 하나로 닫습니다. 닫으면 창을 열었던 버튼으로 커서가 돌아갑니다.
- **삭제 확인:** 새 창을 띄우지 않고, 누른 버튼 자리에 확인 문장과 '삭제', '취소' 버튼이 나옵니다.
- **화면 이동:** 다른 화면으로 가면 열려 있던 작은 창과 알림 창을 닫고 화면 맨 위로 올라갑니다.
- **연락처:** 숫자만 쳐도 010-0000-0000 모양으로 하이픈이 저절로 들어갑니다. 사업자등록번호는 하이픈까지 직접 입력합니다.

| 입력 | 규칙 | 틀렸을 때 문구 |
|---|---|---|
| 이메일(아이디) | 골뱅이(@)와 점이 들어간 이메일 모양 | "이메일 형식으로 입력해 주십시오 (예: name@example.com)" |
| 비밀번호 | 영문과 숫자를 섞어 8~20자, 특수문자는 !@#$%^&*._- 만 | "영문과 숫자를 섞어 8~20자로 입력해 주십시오" |
| 연락처 | 010-0000-0000 모양 (010, 011, 016, 017, 018, 019로 시작) | "010-0000-0000 형식으로 입력해 주십시오" |
| 사업자등록번호 | 000-00-00000 모양 | "000-00-00000 형식으로 입력해 주십시오" |
| 빈 필수 칸 | 앞뒤 빈칸을 지우고 비었는지 확인 | "○○을(를) 입력해 주십시오" |

| 6 | 아이디·비밀번호 찾기 | 링크 | 지원자 탭에만 있습니다. 누르면 찾기 창(SC-A12)이 열립니다. |

**동작 규칙**

- 지원자로 로그인하면 "로그인했습니다"를 띄웁니다. 로그인 전에 '지원하기'를 눌렀다면 그 공고의 환경 점검(SC-A04)으로 바로 이어지고, 아니면 메인으로 갑니다.
- 채용담당자로 로그인하면 "기업회원으로 로그인했습니다"를 띄우고 기업 관리의 대시보드(SC-R13)로 갑니다.
- 와이어프레임은 칸의 형식만 검사합니다. 아이디나 비밀번호가 틀린 경우의 처리는 화면에 없습니다.

- 화면 아래에 "화면에 보이는 기업과 공고는 화면 설계용 예시입니다."가 있습니다.

**동작 규칙**

- 질문 하나는 이 순서로 진행됩니다. 1) 면접관이 질문을 읽습니다(3초). 2) 생각할 시간입니다(10초, 꼬리질문은 5초). 3) 답변합니다(60초, 꼬리질문 45초, 라이브 코딩 3분, 화이트보드 2분). 4) AI가 답변을 분석합니다(2초). 5) 꼬리질문이 필요하면 같은 질문에 이어서 묻고, 아니면 다음 질문으로 갑니다.
- 질문은 다섯 개입니다. 자기소개(인성), 지원 동기, 직무 질문, 경험 질문, 협업 질문 순서입니다. 직무 질문은 개발·데이터·AI 공고에서는 라이브 코딩, 그 밖의 공고에서는 화이트보드에 그리며 설명하는 질문입니다. 개발·데이터·AI 공고의 경험 질문에서는 원하면 화이트보드를 열 수 있습니다.
- 꼬리질문은 면접 전체에서 최대 2개이고, 채용담당자가 면접 질문 관리(SC-R07)에서 바꿀 수 있습니다. 채용담당자가 면접 질문 관리에서 직접 적은 질문이 있으면 그 순서의 질문을 바꿔 냅니다.
- 화이트보드에는 검정·초록·빨강 펜, 지우개, '되돌리기', '모두 지우기', '그림 제출' 버튼이 있습니다. 그림은 이미지로 저장되고 AI가 말로 한 설명과 함께 평가합니다.
- (2026-11-07 끔: PRD SCOPE-9.2, 설정 `AIHIRE_INTERJECT_ENABLED` 기본값 false) 답변이 길어지면 면접관이 끼어듭니다. 말풍선이 '면접관이 끼어들었습니다'로 바뀌고 "말씀 중에 죄송합니다. 답변이 길어지고 있으니 핵심만 30초 안에 정리해 주십시오."를 읽은 뒤, 남은 시간(최대 30초) 동안 이어서 답변합니다.
- 시선이 1.5초 넘게 화면을 벗어나면 경고를 띄우고 횟수를 셉니다. 경고가 3번 이상이면 부정행위 의심으로 기록한다고 알립니다.
- 제한 시간이 끝나면 답변을 저절로 끝냅니다. 마지막 질문을 마치면 면접 완료(SC-A07)로 갑니다.
- 단계 안내의 '말이 3초 넘게 멈추면 답변이 끝난 것으로 봅니다'는 안내 문구만 있고, 와이어프레임은 말이 멈춘 것을 실제로 알아채지 않습니다. 답변은 '답변 완료' 버튼이나 제한 시간으로 끝납니다.
- 이 화면에서는 상단바를 숨깁니다.

| 4 | 답장 | 긴 입력 칸, 버튼 | 답장을 적고 '보내기'를 누르면 대화에 붙고 "쪽지를 보냈습니다"를 띄웁니다. |

## 7. 시연용 장치 (실제 서비스 화면이 아닙니다)

와이어프레임을 시연하려고 넣은 것들입니다. 실제 서비스를 만들 때는 넣지 않습니다.

- **화면 아래 '프로토타입 상태' 막대:** 계정을 바로 바꿉니다(로그인 안 함, 면접자, 기업회원 · 승인 대기, 기업회원 · 승인됨, 운영자). '이력서 작성됨'으로 이력서가 있는 상태와 없는 상태를 바꾸고, '처음부터'로 모든 상태를 처음으로 되돌립니다. 오른쪽에는 지금 화면 이름이 보입니다.
- **AI 면접 중에 막대에 더 생기는 버튼:** '시선 이탈 재현'(시선이 벗어난 상태를 켜고 끔), '답변 길게 끌기 재현'(답변 중에 누르면 면접관이 끼어듦), '영상 위치: 오른쪽/왼쪽'(내 카메라 화면을 왼쪽이나 오른쪽으로 옮김)입니다.
- **'예시 값 채우기' 버튼:** 지원자 회원가입 창의 모든 칸을 예시 값으로 채웁니다.
- **'간단 화면' 꼬리표:** 로그인, 이력서 작성, 면접 완료 화면 위의 '간단 화면 · ○○' 표시는 아직 자세히 그리지 않은 화면이라는 뜻입니다.
- **시연용 시간:** 카메라 확인 약 1초, 마이크 테스트 약 1.6초, 이력서 파일 읽기 약 1.6초, 리포트 만들기 8초, 외부 공고 파일 읽기 약 1.4초, 메일로 보낸 면접 일정 수락 5초입니다. 실제로 걸리는 시간이 아닙니다.
- **입력 칸의 처음 값:** 로그인, 기업회원 가입, 아이디 찾기 칸에 미리 들어 있는 값은 시연을 빠르게 하려는 예시 값입니다.
