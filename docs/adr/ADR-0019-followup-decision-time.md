# ADR-0019: 꼬리질문 판단 시간 제한을 품질 기준으로 쓰지 않는다

- 상태: 채택 (2026-11-05, 사용자 결정)
- 충돌 항목: PRD 6.2 "5초 내 미결정 시 건너뜀", RULE-6.2

## 배경

사용자가 적절히 답변해도 꼬리질문이 계속 건너뛰어졌다. 기록을 보니 건너뜀은 모두 `TIMEOUT`이었고, 약 4.95초에 모델 응답 없이(토큰 0) 끝났다. 공고 정보를 함께 넣은 실제 길이의 답변(프롬프트 약 800토큰, GTX 1660 SUPER 6GB)은 5.1~6.6초가 걸려(6회 측정) 5초 제한으로는 답변 내용과 무관하게 거의 항상 건너뛴다. 6회 중 2회는 인용이 답변 원문과 달라 `INVALID`였고, 재시도가 없어 역시 건너뛰었다.

사용자 판단: 시간이 지났다는 것만으로 건너뛰는 것은 적절하지 않다.

## 결정

- `FOLLOWUP_DECISION_TIMEOUT_SEC`를 30초로 올린다. 모델이 멈춘 경우에만 면접을 넘기는 안전장치로 쓴다.
- 인용 불일치는 1회 재요청하고, 형식 오류는 1회 재시도한다. 인용 검증 자체는 유지한다.

## 영향

- 답변 뒤 다음 질문까지 보통 5~7초, 재요청 시 10~14초 걸린다. PRD 8.2 목표 "답변 종료→다음 질문 5초 안"을 맞추지 못한다. 대기 중에는 "답변을 분석하고 있습니다"를 보여 준다.
- 더 빠른 장비나 더 짧은 프롬프트로 시간을 줄이는 것은 별도 과제다.
