# ADR-0018: 팀 표준 화면정의서의 스타일을 적용한다

- 상태: 채택 (2026-11-05)
- 근거 문서: `Huge_화면정의서_CSS가이드_구현기준_2026-11-05.pptx` (사용자 제공)

## 결정

색 토큰, 글꼴, 크기, 모서리, 그림자와 버튼·입력·카드·칩·배지·알림의 모양은 팀 표준을 따른다. 내부 아키텍처, 라우트, API, 상태 흐름은 바꾸지 않는다 (사용자 지시).

## 영향

- `wireframe-v14.html`은 화면 구조와 클래스 이름의 기준으로 남고, 색·글꼴의 기준은 이 문서로 바뀐다.
- 다크 모드를 없앴다. 표준에 다크 팔레트가 없고 화이트+바이올렛만 승인되어 있다.
- 글꼴: Gothic A1, IBM Plex Sans KR을 빼고 `pretendard@1.3.9`(OFL-1.1)를 번들한다. 외부 요청은 없다 (AC-22).
- 워드마크를 "Huge"로 바꿨다.

## 남은 차이

로그인 분할, 공고 목록 3열, 관리자 사이드바는 옮겼다. 공고 상세, 지원 절차 스테퍼 셸, 응시 화면 격자, 마이페이지·결과 상세, GNB 검색·마스코트 이미지는 아직 옮기지 않았다. 표준 문서의 라우트(`/postings`, `/me` 등)는 코드 기준 설명이라 적용 대상이 아니다.
