원문 JSONL은 공개 저장소에 올리지 않으므로, 로컬 원문으로 직접 확인한 결과를 여기에 남깁니다.

## 1. 전체 60건 자동 점검 (로컬 원문)
| 점검 | 결과 |
|---|---|
| `python -m pytest tests -q` | 11 passed |
| `python scripts/validate.py --check-urls` | 60/60 통과, 검증 오류 0, 출처 URL 60/60 HTTP 200 |
| 본문 중간 저작권 캡션(`© … All rights reserved`) | 수정 전 컬리 5건 → 0건 (`drop_line_patterns`, 검증기가 남으면 오류 처리) |
| 글 끝 행사 소개 문단 | 1건(토스 "토스증권 추천과 검색은…") → 0건 |
| 게시일 null | 수정 전 토스 6건 → 0건 (5건은 제목 아래 표시 날짜로 채움, 1건은 교체된 영어판) |
| 한국어가 아닌 글 | 수정 전 1건(토스 영어판) → 0건 |
| 회사 혼입 | 0건 (`company_id`=파일명, `company_name`=설정값, URL 호스트=그 회사 블로그) |
